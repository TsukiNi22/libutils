    1. GlobalGlobaux

    utils/concepts/GlobalConcepts.hpp

    ConceptSatisfied when
    Convertible<T, U>T can be converted to U
    ConvertibleTo<T, U>T is implicitly convertible to U and static_cast<U>(t) is valid
    Swappable<T>std::swap(a, b) is valid
    Streamable<T>std::ostream << t is valid

    Warning. convertible_to (renamed ConvertibleTo in v3.0.0) was removed in v4.0.0.

    2. OperationsOpérations

    utils/concepts/OperationConcepts.hpp: each one exists for the same type (Addable<T>) and between two types (AddableWith<T, U>).

    Addable / AddableWitha + b
    Subtractable / SubtractableWitha - b
    Multipliable / MultipliableWitha * b
    Divisible / DivisibleWitha / b
    BitwiseAndable / BitwiseAndableWitha & b
    BitwiseOrable / BitwiseOrableWitha | b
    BitwiseXorable / BitwiseXorableWitha ^ b
    Shiftable / ShiftableWitha << b, a >> b

    3. ExampleExemple

    #define _Concepts
#include <utils/utils.hpp>

template<typename T, typename U>
requires utils::concepts::AddableWith<T, U>
auto sum(const T& a, const U& b) {return a + b;}

    4. C++ APIAPI C++

    Read from the headers of include/utils/concepts/ (public part only, the trailing comments of the code kept). Include <utils/utils.hpp> with the define of the section, never these headers one by one.

    utils/concepts/GlobalConcepts.hpp

    Definition of the different global concepts

    // namespace utils::concepts
template<typename T, typename U> concept Convertible = requires(T a, U b);
template<typename T> concept Swappable = requires(T a, T b);
template<typename T> concept Streamable = requires(std::ostream& os, T a);
template<typename T, typename U> concept ConvertibleTo = std::is_convertible_v<T, U> && requires { static_cast<U>(std::declval<T>()); };
