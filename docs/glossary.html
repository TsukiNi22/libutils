    The words used across the library and this documentation.

    Les mots utilisés dans la bibliothèque et dans cette documentation.

    1. LibraryBibliothèque

    WordMeaning
    SectionA part of the library: a folder of include/utils/, a namespace and a define (_Network). Link and include
    GroupA define that enables several sections: _Handling, _Tools, _Utils
    Internal / external codeAn exception code of libutils (InternalCode) / of your project (ExternalCode). Custom exception codes
    Type (of an exception)How serious it is: None, Warning, Error, Fatal, combined as bits. Exception
    RestrictionThe types a code accepts
    failsafeA parameter that turns an error into a printed warning
    safe_modeA parameter that takes a lock (thread safe call)
    ObserverA base class that tracks the instances of a class; the memory leak notifier reports the ones still alive at exit. Security
    Migration / legacyAn old API kept for a time (_migration(x, y, z), removed around that version) or for good (_legacy)
    MotSignification
    SectionUne partie de la bibliothèque : un dossier de include/utils/, un namespace et un define (_Network). Lier et inclure
    GroupeUn define qui active plusieurs sections : _Handling, _Tools, _Utils
    Code interne / externeUn code d'exception de libutils (InternalCode) / de votre projet (ExternalCode). Codes d'exception personnalisés
    Type (d'une exception)Sa gravité : None, Warning, Error, Fatal, combinés en bits. Exceptions
    RestrictionLes types qu'un code accepte
    failsafeUn paramètre qui transforme une erreur en avertissement affiché
    safe_modeUn paramètre qui prend un verrou (appel thread safe)
    ObserverUne classe de base qui suit les instances d'une classe ; le notificateur de fuites mémoire signale celles encore vivantes à la sortie. Security
    Migration / legacyUne ancienne API gardée un temps (_migration(x, y, z), supprimée vers cette version) ou pour de bon (_legacy)

    2. Network and IPCRéseau et IPC

    WordMeaning
    PayloadOne message of a connection, ended by the separator ('\n' by default). Network
    EETPThe protocol of EETPParser: an RSA handshake (SYN, SO) then AES-256-GCM messages. Communication
    Common RSA keyThe key pair shared by both sides of EETP, ~/.ssh/common and ~/.ssh/common.pub
    SlotA fixed size part of a shared memory holding one message. Encapsulation
    OwnershipThe id of a SharedMemory instance (its pid by default), used to address the messages
    TargetWho reads a message of the shared memory: one ownership, or every reader
    MotSignification
    PayloadUn message d'une connexion, terminé par le séparateur ('\n' par défaut). Network
    EETPLe protocole de EETPParser : un handshake RSA (SYN, SO) puis des messages AES-256-GCM. Communication
    Clé RSA communeLa paire de clés partagée par les deux côtés d'EETP, ~/.ssh/common et ~/.ssh/common.pub
    SlotUne partie de taille fixe d'une mémoire partagée qui contient un message. Encapsulation
    OwnershipL'id d'une instance de SharedMemory (son pid par défaut), utilisé pour adresser les messages
    TargetQui lit un message de la mémoire partagée : un ownership, ou tous les lecteurs

    3. C APIAPI C

    WordMeaning
    HandleAn opaque pointer to a C++ object (utils_cli_t*), created by _create and released by _destroy. Use libutils from C
    GuardThe try / catch around each C function that turns an exception into a return value and a status. The C API design
    Statusutils_exception, the thread local record of the last error
    Fixed typesThe C types a template is generated for (i8 ... u64, size, f32, f64, f128, bool, char, str). The C API design
    _r functionThe version of a function that writes its string in your buffer instead of a thread local one
    MotSignification
    HandleUn pointeur opaque vers un objet C++ (utils_cli_t*), créé par _create et libéré par _destroy. Utiliser libutils depuis C
    GardeLe try / catch autour de chaque fonction C qui transforme une exception en valeur de retour et en statut. Conception de l'API C
    Statututils_exception, l'enregistrement thread local de la dernière erreur
    Types fixesLes types C pour lesquels un template est généré (i8 ... u64, size, f32, f64, f128, bool, char, str). Conception de l'API C
    Fonction _rLa version d'une fonction qui écrit sa chaîne dans votre buffer au lieu d'un buffer thread local

    4. BuildBuild

    WordMeaning
    -op / -db / -asThe optimized / debug / AddressSanitizer variant of a package
    -preA pre-release package
    SysrootThe folder of the Windows headers and libraries used by MinGW-w64. Windows
    ToolchainThe CMake file that sets the compilers and the sysroot of a cross compilation
    MotSignification
    -op / -db / -asLa variante optimisée / debug / AddressSanitizer d'un paquet
    -preUn paquet de pré-version
    SysrootLe dossier des headers et bibliothèques Windows utilisés par MinGW-w64. Windows
    ToolchainLe fichier CMake qui définit les compilateurs et le sysroot d'une compilation croisée
