    AttributeAttribute

    Short macros for the compiler attributes, defined for each C++ (11 to 23) and C (99, 11, 23) version: an attribute the version can't use becomes empty.Macros courtes pour les attributs du compilateur, définies pour chaque version de C++ (11 à 23) et de C (99, 11, 23) : un attribut que la version ne peut pas utiliser devient vide.

    Updated 2026-11-27
    DefineGroupNamespaceHeaders
    _Attribute_Utilsmacros (no namespace)utils/attribute/

    Short macros for the compiler attributes, defined from the language and its version, so the code stays the same everywhere: an attribute not supported by the version becomes empty.

    Macros courtes pour les attributs du compilateur, définies selon le langage et sa version, pour que le code reste le même partout : un attribut non pris en charge par la version devient vide.

    1. VersionsVersions

    utils/attribute/Attribute.hpp only chooses the file of the language:

    CompilerFileVersions
    C++c++.hppc++11.hpp, c++14.hpp, c++17.hpp, c++20.hpp, c++23.hpp (forced with FORCED_CXX_STANDARD)
    Cc.hc99.h, c11.h, c23.h (forced with FORCED_C_STANDARD)
    neither / no GNU compilerfallback.hppevery macro empty

    common.hpp / common.h hold what every version shares: _thread_local, _restrict, _alignas and the fallback of std::hardware_destructive_interference_size / std::hardware_constructive_interference_size (64) when the standard library has none. From C++11 / C23 the macros use the [[gnu::...]] syntax.

    utils/attribute/Attribute.hpp choisit seulement le fichier du langage :

    CompilateurFichierVersions

    aucun des deux / pas de compilateur GNUfallback.hppchaque macro vide

    common.hpp / common.h contiennent ce que toutes les versions partagent : _thread_local, _restrict, _alignas et le repli de std::hardware_destructive_interference_size / std::hardware_constructive_interference_size (64) quand la bibliothèque standard n'en a pas. À partir de C++11 / C23, les macros utilisent la syntaxe [[gnu::...]].

    5. In CEn C

    The same macros exist in C: <utils.h> with _Attribute (or _Utils) includes utils/attribute/Attribute.hpp, which picks c.h. An attribute of C++ only (_likely, _unlikely, _noaddress) is empty in C; use _likely_c(c) / _unlikely_c(c) in an expression.

    #define _Attribute
#include <utils.h>

_hot _nodiscard static int parse(const char* s)
{
    if (_unlikely_c(!s))
        return -1;
    return 0;
}

int main(void)
{
    return parse("x");
}

    Les mêmes macros existent en C : <utils.h> avec _Attribute (ou _Utils) inclut utils/attribute/Attribute.hpp, qui choisit c.h. Un attribut propre au C++ (_likely, _unlikely, _noaddress) est vide en C ; utilisez _likely_c(c) / _unlikely_c(c) dans une expression.
