    1. c2dmp-hsmc2dmp-hsm

    _C2DMP: distance between two words, the smaller the closer. Case and Latin-1 accent insensitive, linear time and constant memory. Used for the hints of the Cli.

    template<std::uint_fast8_t prefixDepthSearch = 3, typename UIntT = std::uint_fast8_t, bool full = false>
float c2dmp(std::string_view a, std::string_view b);
    ParameterDescription
    prefixDepthSearchDepth of the common prefix search
    UIntTCounter type (std::uint_fast8_t up to 255 characters, bigger types for longer strings)
    fulltrue: count the misplaced characters of the whole a (c2dmp_foptimized), else c2dmp_optimized

    Variants: c2dmp_optimized, c2dmp_foptimized, c2dmp_simplified, c2dmp_fsimplified (the simplified ones are deprecated).

    #define _C2DMP
#include <utils/utils.hpp>

std::vector<std::string> commands = {"help", "exit", "history"};
std::string typed = "exot";
std::string closest = *std::min_element(commands.begin(), commands.end(), [&](const std::string& a, const std::string& b) {
    return utils::algorithms::c2dmp::c2dmp(typed, a) < utils::algorithms::c2dmp::c2dmp(typed, b);
}); // "exit"

    _C2DMP : distance entre deux mots, plus elle est petite plus ils sont proches. Insensible à la casse et aux accents Latin-1, temps linéaire et mémoire constante. Utilisé pour les suggestions du Cli.

    template<std::uint_fast8_t prefixDepthSearch = 3, typename UIntT = std::uint_fast8_t, bool full = false>
float c2dmp(std::string_view a, std::string_view b);
    ParamètreDescription
    prefixDepthSearchProfondeur de la recherche du préfixe commun
    UIntTType du compteur (std::uint_fast8_t jusqu'à 255 caractères, des types plus grands pour des chaînes plus longues)
    fulltrue : compte les caractères mal placés de tout a (c2dmp_foptimized), sinon c2dmp_optimized

    Variantes : c2dmp_optimized, c2dmp_foptimized, c2dmp_simplified, c2dmp_fsimplified (les simplified sont dépréciées).

    #define _C2DMP
#include <utils/utils.hpp>

std::vector<std::string> commands = {"help", "exit", "history"};
std::string typed = "exot";
std::string closest = *std::min_element(commands.begin(), commands.end(), [&](const std::string& a, const std::string& b) {
    return utils::algorithms::c2dmp::c2dmp(typed, a) < utils::algorithms::c2dmp::c2dmp(typed, b);
}); // "exit"

    2. s.o.ss.o.s

    _SOS: Steganography Optimized and Securized, hides a payload inside a signal (ex: the samples of an audio file) with an imperceptible change, optionally keyed.

    FunctionDescription
    sos_embed<options, magic>(carrier, payload) / (carrier, payload, key)Hide payload in carrier (edited in place)
    sos_extract<magic>(carrier) / (carrier, key)Get the payload back
    tools::to_bytes<ByteT>(range) / tools::bytes_to<Range>(bytes)Convert a string / range to the sample type (Byte = std::uint16_t by default) and back (the result can end with padding)
    OptionEffect
    Option::NoneNo noise, only the samples used to hide the data change
    Option::NoiseNoise generated on every sample before hiding the data
    Option::GlobalNoiseNoise generated only on the samples within the accepted amplitude (the ones that can hold data)

    Warning. The payload can use at most 7.5 % of the signal and the carrier needs enough valid samples: otherwise std::out_of_range; extracting a carrier without hidden message throws std::invalid_argument (the algorithms keep the standard exceptions of their repository).

    #define _SOS
#include <utils/utils.hpp>

std::vector<std::uint16_t> carrier = /* 16 bits samples */;
std::vector<std::uint16_t> payload = utils::algorithms::sos::tools::to_bytes<std::uint16_t>(std::string("secret"));
utils::algorithms::sos::sos_embed(carrier, payload, key);
std::string message = utils::algorithms::sos::tools::bytes_to<std::string>(utils::algorithms::sos::sos_extract(carrier, key));

    _SOS : Steganography Optimized and Securized, cache un payload dans un signal (ex : les échantillons d'un fichier audio) avec une modification imperceptible, éventuellement avec une clé.

    FonctionDescription
    sos_embed<options, magic>(carrier, payload) / (carrier, payload, key)Cache payload dans carrier (modifié sur place)
    sos_extract<magic>(carrier) / (carrier, key)Récupère le payload
    tools::to_bytes<ByteT>(range) / tools::bytes_to<Range>(bytes)Convertit une chaîne / un range vers le type d'échantillon (Byte = std::uint16_t par défaut) et inversement (le résultat peut finir par du padding)
    OptionEffet
    Option::NonePas de bruit, seuls les échantillons utilisés pour cacher les données changent
    Option::NoiseBruit généré sur chaque échantillon avant de cacher les données
    Option::GlobalNoiseBruit généré seulement sur les échantillons dans l'amplitude acceptée (ceux qui peuvent contenir des données)

    Attention. Le payload peut utiliser au plus 7,5 % du signal et la porteuse a besoin d'assez d'échantillons valides : sinon std::out_of_range ; extraire d'une porteuse sans message caché lève std::invalid_argument (les algorithmes gardent les exceptions standard de leur dépôt).

    #define _SOS
#include <utils/utils.hpp>

std::vector<std::uint16_t> carrier = /* 16 bits samples */;
std::vector<std::uint16_t> payload = utils::algorithms::sos::tools::to_bytes<std::uint16_t>(std::string("secret"));
utils::algorithms::sos::sos_embed(carrier, payload, key);
std::string message = utils::algorithms::sos::tools::bytes_to<std::string>(utils::algorithms::sos::sos_extract(carrier, key));

    3. In CEn C

    The C API is a wrapper of libutils, outside the synced sources. The template parameters become arguments read at runtime.

    C++C
    c2dmp<depth, UIntT, full>(a, b)utils_c2dmp(a, a_size, b, b_size, prefix_depth, counter_size, full): prefix_depth from 1 to 5, counter_size 1, 2, 4 or 8 bytes, -1 on error
    c2dmp(a, b) (defaults)utils_c2dmp_default(a, b) ('\0' terminated strings)
    sos_embed<options>(carrier, payload, key)utils_sos_embed_<name>(carrier, count, payload, payload_count, key, key_count, options), <name> = u8, u16, u32, u64, options = C_API_SOS_OPTION_* combined with |
    sos_extract(carrier, key)utils_sos_extract_<name>(carrier, count, key, key_count, out, max): returns the full count of the payload (0 on error)

    The magic of the embedded payloads is fixed to C_API_SOS_MAGIC (0x22) in C. The standard exceptions of the algorithms are reported in utils_exception with the origin C_API_EXCEPTION_ORIGIN_STD.

    #define _C2DMP
#include <utils.h>
#include <stdio.h>

int main(void)
{
    const char* commands[] = {"help", "exit", "history"};
    const char* closest = commands[0];

    for (size_t i = 1; i < 3; ++i)
        if (utils_c2dmp_default("exot", commands[i]) < utils_c2dmp_default("exot", closest))
            closest = commands[i];
    printf("%s\n", closest); // exit
    return 0;
}

    L'API C est un wrapper de libutils, en dehors des sources synchronisées. Les paramètres de template deviennent des arguments lus à l'exécution.

    C++C
    c2dmp<depth, UIntT, full>(a, b)utils_c2dmp(a, a_size, b, b_size, prefix_depth, counter_size, full) : prefix_depth de 1 à 5, counter_size 1, 2, 4 ou 8 octets, -1 en cas d'erreur
    c2dmp(a, b) (valeurs par défaut)utils_c2dmp_default(a, b) (chaînes terminées par '\0')
    sos_embed<options>(carrier, payload, key)utils_sos_embed_<name>(carrier, count, payload, payload_count, key, key_count, options), <name> = u8, u16, u32, u64, options = C_API_SOS_OPTION_* combinées avec |
    sos_extract(carrier, key)utils_sos_extract_<name>(carrier, count, key, key_count, out, max) : renvoie le nombre complet d'éléments du payload (0 en cas d'erreur)

    Le magic des payloads cachés est fixé à C_API_SOS_MAGIC (0x22) en C. Les exceptions standard des algorithmes sont signalées dans utils_exception avec l'origine C_API_EXCEPTION_ORIGIN_STD.

    #define _C2DMP
#include <utils.h>
#include <stdio.h>

int main(void)
{
    const char* commands[] = {"help", "exit", "history"};
    const char* closest = commands[0];

    for (size_t i = 1; i < 3; ++i)
        if (utils_c2dmp_default("exot", commands[i]) < utils_c2dmp_default("exot", closest))
            closest = commands[i];
    printf("%s\n", closest); // exit
    return 0;
}
