The [project graph](graph.html) draws the whole repository: the headers and sources, the classes and functions, the includes, the calls, the tests and the build targets, filtered by category or by relation, in 2D or 3D.

## Use it {#use}

| Action | How |
|---|---|
| Find a file, a class or a function | the search box of the graph |
| Show only one kind of node or relation | the filters (categories, groups, relations) |
| See what depends on a node | select it: its neighbors are highlighted |
| Switch the view | the 2D / 3D button |
