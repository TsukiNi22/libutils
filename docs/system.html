    1. IdHandlerIdHandler

    IdHandler<T> (T integer) gives unique ids and reuses the freed ones first. For an unsigned T the ids start at 1 (0 is reserved as "no id"); for a signed T they start at std::numeric_limits<T>::min(). Every method takes safe_mode = true (lock, thread safe).

    MethodDescription
    allocate() / allocate(T& id)Give a free id (and store it in id)
    free(id)Give back an id (DoubleFree, UnknownId for an id never given)
    use(id)Force an id as used (DoubleUse when already used)
    preview()Next id allocate would give
    id() / actual()Counter / last id given
    clear() / free()Free every id

    Warning. When the type limit is reached, allocate throws FatalException(IdOverflow) (ends the program), preview an ErrorException(IdOverflow).

    IdHandler<T> (T entier) donne des ids uniques et réutilise d'abord ceux qui ont été libérés. Pour un T non signé, les ids commencent à 1 (0 est réservé pour « pas d'id ») ; pour un T signé, ils commencent à std::numeric_limits<T>::min(). Chaque méthode prend safe_mode = true (verrou, thread safe).

    MéthodeDescription
    allocate() / allocate(T& id)Donne un id libre (et le stocke dans id)
    free(id)Rend un id (DoubleFree, UnknownId pour un id jamais donné)
    use(id)Force un id comme utilisé (DoubleUse s'il est déjà utilisé)
    preview()Prochain id que donnerait allocate
    id() / actual()Compteur / dernier id donné
    clear() / free()Libère tous les ids

    Attention. Quand la limite du type est atteinte, allocate lance FatalException(IdOverflow) (termine le programme), preview une ErrorException(IdOverflow).

    2. SchedulerScheduler

    Runs a function after a delay, each task on its own thread.

    MethodDescription
    schedule(delay, fn)Run fn() after delay (std::chrono::milliseconds), returns the task id
    cancel(id)Cancel one task (UnknownId when finished / unknown)
    cancel()Cancel every pending task (also done by the destructor)

std::size_t id = scheduler.schedule(std::chrono::milliseconds{500}, [](void) {std::cout << "later" << std::endl;});
scheduler.cancel(id);

    Exécute une fonction après un délai, chaque tâche sur son propre thread.

    MéthodeDescription

    3. LoadBalancerLoadBalancer

    LoadBalancer<T>(limit = 1, lifespan = 0ms) keeps a pool of workers (T is a utils::type::Worker or derives it, see Type) and gives a free one.

    MethodDescription
    spawn(n = 1)Add n workers (OutOfBounds over the limit, 0 = no limit)
    getWorker()std::future<T&> resolved with a free worker, marked working (waits until one is free)
    kill() / kill(n)Remove the free workers / n workers (the free ones first)
    kill<true>() / kill<true>(n)Same, also removing the working ones
    setLimit(n) / getLimit()Maximum number of workers
    setLifespan(ms) / getLifespan()A worker free for longer is removed (0 = never)
    size()Number of workers

    The worker is given back with worker.setWorkingStatus(false). A getWorker still waiting when the balancer is destroyed throws PromiseCanceled from future.get().

    utils::system::LoadBalancer<utils::type::Worker> balancer(4, std::chrono::seconds{30});
balancer.spawn(2);
utils::type::Worker& worker = balancer.getWorker().get();
// ... work ...
worker.setWorkingStatus(false);

    LoadBalancer<T>(limit = 1, lifespan = 0ms) garde un pool de workers (T est un utils::type::Worker ou en dérive, voir Type) et en donne un libre.

    MéthodeDescription
    spawn(n = 1)Ajoute n workers (OutOfBounds au-delà de la limite, 0 = sans limite)
    getWorker()std::future<T&> résolu avec un worker libre, marqué occupé (attend qu'un worker se libère)
    kill() / kill(n)Supprime les workers libres / n workers (les libres d'abord)
    kill<true>() / kill<true>(n)Pareil, en supprimant aussi ceux qui sont occupés
    setLimit(n) / getLimit()Nombre maximum de workers
    setLifespan(ms) / getLifespan()Un worker libre depuis plus longtemps est supprimé (0 = jamais)
    size()Nombre de workers

    Le worker est rendu avec worker.setWorkingStatus(false). Un getWorker encore en attente quand le balancer est détruit lance PromiseCanceled depuis future.get().

    utils::system::LoadBalancer<utils::type::Worker> balancer(4, std::chrono::seconds{30});
balancer.spawn(2);
utils::type::Worker& worker = balancer.getWorker().get();
// ... work ...
worker.setWorkingStatus(false);

    4. HybridMemoryHybridMemory

    HybridMemory<T> (T trivially copyable, header utils/system/HybridMemory.hpp) keeps n values of T in the memory of a GPU when one is available, else in the RAM, for future computes on it. The backend is chosen at the construction with a MemoryMode; the GPU libraries are loaded at runtime (dlopen / LoadLibrary), so nothing is needed to build or link and a machine without GPU simply uses the RAM.

    ModeBackend
    AutoFirst GPU found (Cuda → OpenCL → Vulkan), else the RAM
    GpuFirst GPU found, GpuUnavailable without one
    RamHost memory only
    Cuda / OpenCL / VulkanForced backend (libcuda / libOpenCL / libvulkan), GpuUnavailable when missing
    CustomHandler given by the program (IGpu, see below)
    MethodDescription
    HybridMemory(mode = Auto) / HybridMemory(size, mode = Auto)Select the backend (and allocate size values)
    HybridMemory(size, std::shared_ptr<IGpu> gpu)Custom mode with a handler (InvalidArgument when nullptr or unavailable)
    allocate(size) / resize(size) / free()New memory (uninitialized) / new size, the first values kept / release
    store(span<const T>, offset = 0)Copy values into the memory from the index offset (OutOfBounds)
    fetch(span<T>, offset = 0)Copy out.size() values from the memory (OutOfBounds)
    get(i) / set(i, value) / operator[]One value (a transfer on the GPU: prefer fetch / store for many)
    fill(value) / clear()Every value set to value / to 0
    toVector()Whole memory copied in a std::vector<T>
    join()Wait for the pending GPU operations (nothing in RAM)
    getMode() / getRequestedMode() / isOnGpu()Mode really used (Ram after an Auto without GPU) / mode asked / on a GPU handler
    size() / bytes() / empty()Number of T / size in bytes / nothing allocated
    native()Device buffer (CUdeviceptr, cl_mem...) for the computes, 0 in RAM
    data()Host pointer (RAM only, nullptr on a GPU)
    getGpu()The handler (IGpu), nullptr in RAM

    The class is move only. IGpu (utils/system/gpu/IGpu.hpp) is the interface of a backend, implemented by CudaGpu, OpenCLGpu and VulkanGpu: isAvailable, getMode, getName, getMemory, allocate, free, store, fetch, memset, memcpy, join (offsets in bytes). make_gpu(mode) (and make_raw_gpu / make_shared_gpu / make_unique_gpu) builds one by hand, nullptr for Ram.

    HybridMemory only stores and moves the data: the computes are written with the API of the backend on native() (kernel launch, cl_mem argument...). Every call of the Cuda handler makes its context current on the calling thread.

    Warning. On a GPU every get / set is a transfer, and the Vulkan handler creates a staging buffer for each one: use store / fetch for blocks.

    HybridMemory<T> (T trivialement copiable, en-tête utils/system/HybridMemory.hpp) garde n valeurs de T dans la mémoire d'un GPU quand il y en a un, sinon dans la RAM, pour de futurs calculs dessus. Le backend est choisi à la construction avec un MemoryMode ; les bibliothèques GPU sont chargées à l'exécution (dlopen / LoadLibrary), donc rien n'est nécessaire pour le build ou l'édition de liens, et une machine sans GPU utilise simplement la RAM.

    ModeBackend
    AutoPremier GPU trouvé (Cuda → OpenCL → Vulkan), sinon la RAM
    GpuPremier GPU trouvé, GpuUnavailable s'il n'y en a pas
    RamMémoire de l'hôte seulement
    Cuda / OpenCL / VulkanBackend forcé (libcuda / libOpenCL / libvulkan), GpuUnavailable s'il manque
    CustomHandler fourni par le programme (IGpu, voir plus bas)
    MéthodeDescription
    HybridMemory(mode = Auto) / HybridMemory(size, mode = Auto)Choisit le backend (et alloue size valeurs)
    HybridMemory(size, std::shared_ptr<IGpu> gpu)Mode Custom avec un handler (InvalidArgument quand il vaut nullptr ou est indisponible)
    allocate(size) / resize(size) / free()Nouvelle mémoire (non initialisée) / nouvelle taille, les premières valeurs étant gardées / libération
    store(span<const T>, offset = 0)Copie des valeurs dans la mémoire à partir de l'indice offset (OutOfBounds)
    fetch(span<T>, offset = 0)Copie out.size() valeurs depuis la mémoire (OutOfBounds)
    get(i) / set(i, value) / operator[]Une valeur (un transfert sur le GPU : préférez fetch / store pour beaucoup de valeurs)
    fill(value) / clear()Toutes les valeurs mises à value / à 0
    toVector()Toute la mémoire copiée dans un std::vector<T>
    join()Attend les opérations GPU en cours (rien en RAM)
    getMode() / getRequestedMode() / isOnGpu()Mode réellement utilisé (Ram après un Auto sans GPU) / mode demandé / sur un handler GPU
    size() / bytes() / empty()Nombre de T / taille en octets / rien d'alloué
    native()Buffer du device (CUdeviceptr, cl_mem...) pour les calculs, 0 en RAM
    data()Pointeur hôte (RAM seulement, nullptr sur un GPU)
    getGpu()Le handler (IGpu), nullptr en RAM

    La classe est seulement déplaçable. IGpu (utils/system/gpu/IGpu.hpp) est l'interface d'un backend, implémentée par CudaGpu, OpenCLGpu et VulkanGpu : isAvailable, getMode, getName, getMemory, allocate, free, store, fetch, memset, memcpy, join (offsets en octets). make_gpu(mode) (et make_raw_gpu / make_shared_gpu / make_unique_gpu) en construit un à la main, nullptr pour Ram.

    HybridMemory ne fait que stocker et déplacer les données : les calculs s'écrivent avec l'API du backend sur native() (lancement de kernel, argument cl_mem...). Chaque appel du handler Cuda rend son contexte courant sur le thread appelant.

    Attention. Sur un GPU, chaque get / set est un transfert, et le handler Vulkan crée un staging buffer pour chacun : utilisez store / fetch pour des blocs.

    5. ExampleExemple

#include <utils/utils.hpp>
#include <vector>

std::vector<float> values = {1.0f, 2.0f, 3.0f, 4.0f};
std::vector<float> out(values.size());

utils::system::HybridMemory<float> memory(values.size());   // Auto: GPU when available, else RAM
memory.store(values);                                       // host -> memory
memory.set(0, 10.0f);                                       // one value
memory.join();                                              // wait for the GPU
memory.fetch(out);                                          // memory -> host: {10, 2, 3, 4}

    utils/system/gpu/IGpu.hpp

    Interface of a gpu handler used by the HybridMemory

    // namespace utils::system
using GpuBuffer = std::uintptr_t; // opaque device buffer of a handler (CUdeviceptr, cl_mem, Vulkan allocation...), 0 = none
class IGpu {
    virtual bool isAvailable(void) const = 0; // backend loaded and a device ready
    virtual utils::system::MemoryMode getMode(void) const = 0; // Cuda | OpenCL | Vulkan | Custom
