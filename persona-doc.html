Welcome to Persona

Custom newsletter manager with session-based authentication and GDPR-first data handling, powered by n8n workflows and a lightweight LLM intent classifier.

01 Import workflows

Each .json file is a standalone n8n workflow. Import them one by one following the steps below.

1

Open n8n and go to Workflows

In the left sidebar, click Workflows then + New workflow in the top-right corner.

2

Import from file

In the blank editor, open the ⋯ menu (top right) → Import from File. Select one of the .json files from the project folder.

3

Repeat for all 11 files

Import each workflow separately. Sub-workflows are referenced by name — make sure the names match exactly once imported.

4

Check for orange nodes

Orange nodes indicate missing credentials. Assign the correct credential to each node (see section 02) before activating.

5

Activate all workflows

Toggle each workflow to Active. The main webhook and both schedule triggers must be active for the system to function.

03 Choose a LLM

The Ai - Info Handling sub-workflow sends the raw user message to a language model whose only job is to output a single intent keyword. The task is simple — you don't need a powerful or expensive model.

"Tant qu'elle est pas trop conne"

— Gaëtan, lead dev

Any model capable of basic text comprehension and instruction-following is sufficient. Free-tier API keys are perfectly adequate for this use case.

mistral-small-latest — fast, lightweight, free tier available. Ideal pick for intent classification.

— Session & identity

Authentication uses two identifiers that must be present together on every protected request.

🎟️

token — session token

Generated at login by Create Session Token, stored in the session table, and returned to the client. Expires after 24 hours. Must be sent in the request header on every call after login.

💬

chatSessionId — conversation identity

The n8n chat session ID that ties the conversation thread to the user. Used alongside the token to identify who is making the request, without exposing the email to intermediate nodes.

✅

Commands that require authentication (logout, delete_account, display_account, and all update intents) will be rejected if the token is missing, invalid, or expired. Only help and login are accessible without a session.

— GDPR compliance

Persona is built with GDPR as a first-class constraint, not an afterthought. Here are the key mechanisms in place.

✓

Explicit consent at registration

The consent field (bool) and consent_at timestamp are recorded when a user registers. No account is created without consent.

✓

Sensitive data hashed & user-only

Passwords are stored as bcrypt hashes — never in plain text. Sensitive fields are only accessible through authenticated user-initiated actions. The LLM never touches this data.

✓

Right to erasure — delete_account

The Delete Account sub-workflow performs a complete, immediate deletion of all rows in both the users and session tables for the requesting user.

✓

Automatic inactivity purge (2-year rule)

The RGPD - Schedule Trigger runs daily at midnight. It deletes any user whose expires_at has passed (2 years from last activity), removing all associated data.

✓

Session token expiry — 24h

Session tokens carry an expires_at timestamp. The daily midnight schedule cleans up all expired tokens automatically.

✓

Data minimisation

Only strictly necessary data is collected: email, preferences, schedule, and consent. No behavioural tracking, no analytics, no third-party data sharing.

User Guide · v1.0

Using Persona

Everything you need to know to manage your custom newsletter through the chatbot — no technical knowledge required.

— What is Persona?

Persona is a newsletter chatbot. Instead of filling out forms or clicking through settings pages, you simply chat with it in plain language and it takes care of the rest.

You tell it what topics you care about, when you want your newsletter delivered, and how many articles you want — and it handles everything automatically.

💬

Just type naturally. The chatbot understands many ways of saying the same thing. You don't need to use exact keywords — write as you would in a normal conversation.

— How the chat works

Every message you send goes through the same simple pipeline. The chatbot reads your message, figures out what you want to do, and responds accordingly.

💬 Your message
→
🤖 Intent detection
→
⚙️ Action
→
✅ Response

The system detects what you want to do from your message — this is called an intent. You never need to type exact commands. For example, all of these are understood as the same action:

show me my account info
what are my current settings?
display my data
what do you have on me
🔒

Most actions require you to be logged in first. If you're not authenticated, the chatbot will ask you to log in or create an account.

— Create an account

You need an account to use Persona. Registration is done directly through the chat — just tell it you want to sign up and provide your email and a password.

🆕 Register login

Say that you want to create or register an account. The chatbot will ask for your email address and a password in a single message.

Format your credentials like this: email@example.com password yourpassword

I want to create an account — email: hello@example.com password: secret123
register me with test@mail.com pass mysecurepass
sign up email@domain.com password 1234

⚠️ Your password is sent exactly as you type it — double-check for typos. It is stored as a secure hash and never readable by anyone.

✅

On first login, you will be asked to give your consent for data processing in compliance with GDPR. This is required to create an account.

— Login & logout

🔑 Login login

Tell the chatbot you want to log in and provide your credentials. Your session is valid for 24 hours — after that, you'll need to log in again.

log me in hello@example.com password secret123
login with test@mail.com pass mysecurepass
sign in email@domain.com password 1234
🚪 Logout 🔒 requires login

End your session. Your session token is invalidated immediately.

log me out
logout
sign out
🟢 Help always available

At any time, ask for help to see the list of available actions. This works even when you're not logged in.

help
what can you do?
show me what's possible

— Your account

👤 View your account 🔒 requires login

Display your current profile: email, subscription status, interests, schedule, and article count.

show my account
what are my settings?
display my data
🗑️ Delete your account 🔒 requires login

Permanently delete your account and all associated data. This action is immediate and irreversible — all your data is erased from the system.

delete my account
remove all my data
I don't want my account anymore

⚠️ This cannot be undone. Your email, preferences, and session will all be permanently removed.

— Newsletter settings

✉️ Subscribe to the newsletter 🔒 requires login

Start receiving your personalised newsletter at your chosen time.

subscribe me

🔕 Unsubscribe 🔒 requires login

Stop receiving newsletters. Your account and preferences are kept — you can re-subscribe at any time.

unsubscribe me

📰 Get your newsletter now 🔒 requires login

— Interests

Interests are the topics used to personalise your newsletter. You can add or remove them at any time. Just name the topics naturally — the chatbot extracts them automatically.

➕ Add interests 🔒 requires login

Tell the chatbot what topics you'd like to follow. You can add multiple at once.

I like space, AI and cybersecurity
add science and startups to my interests
I'm interested in gaming and design
➖ Remove interests 🔒 requires login

Remove topics you no longer want in your newsletter.

remove gaming from my interests
I don't want space anymore
delete science from my topics

— Schedule & article count

📅 Set delivery time 🔒 requires login

Choose when you want to receive your newsletter each day. The chatbot understands a wide range of time expressions — natural language works fine.

send me the newsletter at 8am
set my schedule to 9pm
I want it at half past seven in the morning
deliver at quarter past 6 in the evening

Supported formats: 9am, 21h, quarter past X, half past X, around X (if time is explicit)

🔢 Set number of articles 🔒 requires login

Choose how many articles you want in each newsletter. Provide a clear, explicit number — the chatbot won't guess if it's ambiguous.

send me 5 articles per newsletter
I want 3 news items
set my newsletter count to 10

Note: if your message contains multiple numbers, the one that refers to a quantity or count will be used. Vague expressions like "around ten" won't be accepted.

— Your privacy

Persona is designed to handle your data with care and full GDPR compliance. Here's what that means for you as a user.

🔒

Your password is never stored

Passwords are hashed before storage. No one — including the system administrators — can read your password.

⏰

Sessions expire in 24h

Your login session is automatically invalidated after 24 hours. You'll need to log in again to continue.

🗑️

Delete your data, anytime

You can permanently erase your account and all associated data at any time with a single message.

📅

Automatic deletion after 2 years

Inactive accounts are automatically deleted after 2 years of inactivity to respect data minimisation principles.

🤖

The AI never sees your data

The language model only receives your text message to classify your intent. It has no access to your account data, email, or preferences.

✅

Consent is required

Your explicit consent is recorded at registration, along with a timestamp. No account is created without it.
