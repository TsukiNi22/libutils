    PlatformPlatform

    The system calls used by the whole library, with the names and contract of POSIX on Unix and on Windows, and the platform macros.Les appels système utilisés par toute la bibliothèque, avec les noms et le contrat de POSIX sous Unix et sous Windows, et les macros de plateforme.

    Updated 2026-11-26
    DefineGroupNamespaceHeaders
    _Platform_Toolsutils::platformutils/platform/

    The system calls used by the whole library, with the same names, arguments and contract as POSIX (-1 and errno on error): the system call on Unix, a Win32 / Winsock / CRT implementation on Windows. A code written with them builds on both platforms without any #ifdef. Why and how: Platforms.

    DefineGroupeNamespaceHeaders
    _Platform_Toolsutils::platformutils/platform/

    Les appels système utilisés par toute la bibliothèque, avec les mêmes noms, arguments et contrat que POSIX (-1 et errno en cas d'erreur) : l'appel système sous Unix, une implémentation Win32 / Winsock / CRT sous Windows. Un code écrit avec eux compile sur les deux plateformes sans aucun #ifdef. Pourquoi et comment : Plateformes.

    3. Windows behaviorComportement sous Windows

    CallWindows implementation
    closeAny fd: CRT fd (_close), socket (closesocket) or emulated epoll
    read / writeCRT (_read / _write), recv / send on a socket
    pipe / dup / dup2CRT _pipe (binary mode) / _dup / _dup2
    pollWSAPoll for sockets; console, pipe and file input checked by slices of 10 ms
    readlink"/proc/self/exe" = GetModuleFileName, else a symbolic link
    strerrorAlso the socket errors (message of the Winsock code), in English
    socket callsWinsock 2, started on the first use; WSAGetLastError translated in errno (WSAECONNREFUSED → ECONNREFUSED...); SO_SNDTIMEO / SO_RCVTIMEO take a timeval; SO_REUSEADDR is the default behavior (no-op)
    epoll_*Emulation over WSAPoll: sockets only (ENOTSOCK), level triggered (EPOLLET → EINVAL), EPOLLONESHOT emulated, at most 10 ms of latency
    dlopen / dlsym / dlclose / dladdrLoadLibraryA / GetProcAddress / FreeLibrary / GetModuleHandleExA + GetModuleFileNameA
    tcgetattr / tcsetattrConsole mode: ICANON = line input, ECHO = echo, ISIG = ctrl+c; without ICANON the input gives the escape sequences (VT input)

    Warning. The complete <windows.h> declares a member named _unused, a libutils attribute macro: include <windows.h> before <utils/utils.hpp>, or define WIN32_LEAN_AND_MEAN.

    AppelImplémentation Windows
    closeN'importe quel fd : fd CRT (_close), socket (closesocket) ou epoll émulé
    read / writeCRT (_read / _write), recv / send sur une socket
    pipe / dup / dup2_pipe CRT (mode binaire) / _dup / _dup2
    pollWSAPoll pour les sockets ; entrée console, pipe et fichier vérifiée par tranches de 10 ms
    readlink"/proc/self/exe" = GetModuleFileName, sinon un lien symbolique
    strerrorAussi les erreurs des sockets (message du code Winsock), en anglais
    appels socketWinsock 2, démarré à la première utilisation ; WSAGetLastError traduit en errno (WSAECONNREFUSED → ECONNREFUSED...) ; SO_SNDTIMEO / SO_RCVTIMEO prennent un timeval ; SO_REUSEADDR est le comportement par défaut (sans effet)
    epoll_*Émulation au-dessus de WSAPoll : sockets uniquement (ENOTSOCK), déclenchement sur niveau (EPOLLET → EINVAL), EPOLLONESHOT émulé, au plus 10 ms de latence
    dlopen / dlsym / dlclose / dladdrLoadLibraryA / GetProcAddress / FreeLibrary / GetModuleHandleExA + GetModuleFileNameA
    tcgetattr / tcsetattrMode de la console : ICANON = saisie par ligne, ECHO = écho, ISIG = ctrl+c ; sans ICANON l'entrée donne les séquences d'échappement (entrée VT)

    Attention. Le <windows.h> complet déclare un membre nommé _unused, une macro d'attribut de libutils : incluez <windows.h> avant <utils/utils.hpp>, ou définissez WIN32_LEAN_AND_MEAN.

    5. ErrorsErreurs

    The calls never throw: they return -1 (nullptr for dlopen / dlsym, an EAI_* code for getaddrinfo) and set errno (dlerror for the dynamic loading), like the system calls. The classes built on them (Encapsulation, Network, Cli) turn these errors into exceptions.

    Les appels ne lèvent jamais d'exception : ils renvoient -1 (nullptr pour dlopen / dlsym, un code EAI_* pour getaddrinfo) et définissent errno (dlerror pour le chargement dynamique), comme les appels système. Les classes construites au-dessus (Encapsulation, Network, Cli) transforment ces erreurs en exceptions.

    6. In CEn C

    Every call is utils_platform_<name> with the same contract (-1 and errno, no utils_exception). dladdr fills a utils_platform_dl_info_t instead of Dl_info (which needs _GNU_SOURCE).

    In strict C (-std=c11, -std=c23) on Unix, the POSIX structures of these calls need the POSIX features: #define _POSIX_C_SOURCE 200809L before the first include (already the default with -std=gnu11 / gnu23).

    #define _POSIX_C_SOURCE 200809L
#define _Platform
#include <utils.h>
#include <errno.h>
#include <stdio.h>

int main(void)
{
    int fds[2];
    char buf[3] = {0};

    if (utils_platform_pipe(fds) != 0)                          // -1 & errno on error, like POSIX
        return 1;
    utils_platform_write(fds[1], "ok", 2);
    utils_platform_read(fds[0], buf, 2);                        // "ok"
    utils_platform_close(fds[0]);
    utils_platform_close(fds[1]);
    printf("%s %s\n", buf, utils_platform_strerror(ECONNREFUSED)); // "Connection refused" (Unix & Windows)
    return 0;
}

    Chaque appel est utils_platform_<name> avec le même contrat (-1 et errno, pas de utils_exception). dladdr remplit un utils_platform_dl_info_t au lieu de Dl_info (qui a besoin de _GNU_SOURCE).

    En C strict (-std=c11, -std=c23) sous Unix, les structures POSIX de ces appels ont besoin des fonctionnalités POSIX : #define _POSIX_C_SOURCE 200809L avant le premier include (déjà le cas par défaut avec -std=gnu11 / gnu23).
