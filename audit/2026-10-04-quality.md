Fix: split by phase (`parseFlags_`: long / short / value parsing; `getInput_`: escape sequences, history, buffer edition). Readability only.

### 3.2 Root leftovers (low)

`a.out`, `tmp.cpp`, `main.cpp`, `client.cpp`, `server.cpp`, `latex/` (stale Doxygen output) are ignored by git but stay at the root. Fix: move the scratch programs into an ignored `sandbox/` folder, delete the generated `a.out` / `latex/`.

### 3.3 Public names not referenced by the tests (low)

| Kind | Names | Note |
|---|---|---|
| migration aliases (deprecated) | `readMouseEvent`, `readAdvancedMouseEvent`, `readCursorPosition`, `setStyle`, `resetStyle` | forward to the tested new names |
| interfaces / abstract | `ISocket`, `IObserver`, `AObserver`, `AException`, `AParser` | exercised through their implementations |
| internal types | `ParsedUsageFull`, `Usage`, `SettingsHash`, `ShmMetadata`, `Slot`, `MiddlewareType`, `Char`, `demangle` | used by the tested code paths, not by name |
| vendored internals | `DirectSeedSequence`, `clamp_to_byte`, `make_generator`, `normalize_`, `makeLookupTable_`, `sos_embed_optimized`, `sos_extract_optimized` | covered through `sos_embed` / `sos_extract` and the c2dmp entry points |

### 3.4 Compiler warnings (low)

14 warnings in `include/utils/algorithms/c2dmp-hsm/algorithm/{f,}optimized.hpp` (`char` → unsigned, `size_t` → `float`). Vendored: to fix upstream in `TsukiNi22/c2dmp-hsm`, a local fix would be erased by the next sync.

### 3.5 Commits (low)

Rule (`git-conventions`): `type(scope): message`. 4 / 196 commits use `type(scope)~:` (`84c0f43`, `3a4f458`, `7912afb`, `26b7465`), `84c0f43` has the typo `depreacted`. Old history: only avoid the `~` marker.

### 3.6 False positives (not counted)

- **Trailing spaces**: all on line 3 of the Xartania banner (the ASCII art line ends with a space in the template).
- **`auto`**: `tests/type/Matrix.cpp:328,331`, `tests/type/Vector.cpp:171,174,329` check the deduced type with `decltype`; `main.cpp:130` is scratch code.
- **CMake sources**: `client.cpp`, `main.cpp`, `tmp.cpp` are ignored scratch files.
- **Include guards**: `c++14.hpp` → `ATTRIBUTE_CPP14_H` (a `+` can't be in a macro), `fixed_string.hpp` → `FIXED_STRING_H`, vendored `C2DMP_*` prefixes, generated header, guard-less umbrellas by design.

## 4. Priorities

1. **Split `parseFlags_` / `getInput_`.** Gain: readability of the two most complex parsers. Effort: medium, covered by the tests.
2. **Fix the 14 `c2dmp-hsm` conversions upstream** and add an SPDX line in the sync `sed` step. Effort: small, in the upstream repositories.
3. **Clean the root** (`sandbox/` for the scratch programs, delete `a.out` / `latex/`). Effort: minutes.
