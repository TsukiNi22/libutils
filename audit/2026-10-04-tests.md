## 2. Method

| Item | Value |
|---|---|
| Build | `clang++`, `-DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTS=ON`, `-fprofile-instr-generate -fcoverage-mapping`, separate build folder in `/tmp` |
| Run | `ctest --timeout 30 -j$(nproc)`, one profile per process (`LLVM_PROFILE_FILE=%p.profraw`, the `ISOLATED` sub-processes are counted) |
| Coverage | `llvm-profdata merge` + `llvm-cov report`, without `tests/`, system headers and the generated exception header |
| Inventory | `untested.py --methods` |
| Limits | a name referenced is not a behaviour tested; templates only count where instantiated; the vendored algorithms are included |

## 5. Remaining gaps

1. **`autoCast` dead cases** (`Settings.hpp:126-157`): let `getType_` return those types or drop the cases (design choice).
2. **Syscall / OpenSSL failure paths**: need fault injection (an `ISocket` mock for the network; OpenSSL failures aren't reachable without a custom provider).
3. **Branch coverage 74 %**: mostly error codes; add `catch (IException&) {EXPECT_EQ(code)}` cases to the existing suites.
