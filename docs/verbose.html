    VerboseVerbose

    A global verbose level and output macros that only print when the level is high enough, under one lock shared by every thread.Un niveau de verbosité global et des macros de sortie qui n'affichent que si le niveau est assez élevé, sous un seul verrou partagé par tous les threads.

    Updated 2026-11-26
    DefineGroupNamespaceHeader
    _Verbose_Handlingutils::verboseutils/verbose/Verbose.hpp

    A global verbose level and macros that only print when the level is high enough. Every output is done under one recursive lock (utils::verbose::output_lock), so the lines of several threads never mix.

    DefineGroupeNamespaceHeader
    _Verbose_Handlingutils::verboseutils/verbose/Verbose.hpp

    Un niveau de verbosité global et des macros qui n'affichent que si le niveau est assez élevé. Chaque sortie se fait sous un seul verrou récursif (utils::verbose::output_lock), donc les lignes de plusieurs threads ne se mélangent jamais.

    1. LevelsNiveaux

    utils::verbose::verbose is a std::atomic<utils::verbose::Verbose> (default Basic): it can be changed while other threads log.

    LevelValueDisplayed
    None0nothing
    Basic1onBasicVerbose
    Advanced2onBasicVerbose, onAdvancedVerbose
    Debug3everything, the onDebugVerbose lines start with debug:

    utils::verbose::verbose est un std::atomic<utils::verbose::Verbose> (Basic par défaut) : il peut être changé pendant que d'autres threads écrivent des logs.

    NiveauValeurAffiché

    Advanced2onBasicVerbose, onAdvancedVerbose
    Debug3tout, les lignes onDebugVerbose commencent par debug:

    2. MacrosMacros

    MacroDescription
    set_verbose(level)Set the global level (set_verbose(Debug))
    onBasicVerbose(info) / onAdvancedVerbose(info) / onDebugVerbose(info)Print info on std::cout (a stream expression: "x = " << x)
    onVerbose(level, info)Same with a level given at runtime
    onBasicVerboseC(output, info) ... onVerboseC(output, level, info)Same on another stream (std::cerr, a file...)
    onBasicVerboseFn(code) ... onVerboseFn(level, code)Run a block of code under the output lock when the level is reached
    LOCK_OUTPUTLock the output for the current scope (raw writes mixed with the verbose ones)
    utils::verbose::locked(fn)Run fn with the output locked (used by every macro)

    The lock is recursive: a verbose macro can be called inside a *Fn block.

    MacroDescription
    set_verbose(level)Définit le niveau global (set_verbose(Debug))
    onBasicVerbose(info) / onAdvancedVerbose(info) / onDebugVerbose(info)Affiche info sur std::cout (une expression de flux : "x = " << x)
    onVerbose(level, info)Pareil avec un niveau donné à l'exécution
    onBasicVerboseC(output, info) ... onVerboseC(output, level, info)Pareil sur un autre flux (std::cerr, un fichier...)
    onBasicVerboseFn(code) ... onVerboseFn(level, code)Exécute un bloc de code sous le verrou de sortie quand le niveau est atteint
    LOCK_OUTPUTVerrouille la sortie pour la portée courante (écritures brutes mêlées à celles du verbose)
    utils::verbose::locked(fn)Exécute fn avec la sortie verrouillée (utilisé par chaque macro)

    Le verrou est récursif : une macro verbose peut être appelée dans un bloc *Fn.

    3. ExampleExemple

    #define _Verbose
#include <utils/utils.hpp>

int main(void)
{
    set_verbose(Advanced);
    onBasicVerbose("Starting " << 3 << " workers...");
    onDebugVerbose("never displayed (level Advanced)");
    onAdvancedVerboseC(std::cerr, "on the error output");
    onBasicVerboseFn(
        for (int i = 0; i < 3; ++i)
            std::cout << i << std::endl;
    );
    return 0;
}

    4. In CEn C

    The same global level, with printf style logs locked like the C++ macros (the C and C++ logs of one program never mix).

    C++C
    set_verbose(Advanced) / verbose.load()utils_verbose_set(C_API_VERBOSE_ADVANCED) / utils_verbose_get()
    onVerbose(level, info)utils_verbose_log(level, fmt, ...) (utils_verbose_vlog with a va_list)
    onVerboseC(output, level, info)utils_verbose_log_to(FILE*, level, fmt, ...)
    utils::verbose::locked(fn)utils_verbose_locked(fn, data)
    onVerboseFn(level, code)utils_verbose_on(level, fn, data)
    #define _Verbose
#include <utils.h>
#include <stdio.h>

static int dump(void* data)
{
    printf("%d workers\n", *(int*)data); // the output is locked while fn runs
    return UTILS_OK;
}

int main(void)
{
    int workers = 3;

    utils_verbose_set(C_API_VERBOSE_ADVANCED);
    utils_verbose_log(C_API_VERBOSE_BASIC, "Starting %d workers...", workers);
    utils_verbose_log(C_API_VERBOSE_DEBUG, "never displayed (level ADVANCED)");
    utils_verbose_log_to(stderr, C_API_VERBOSE_ADVANCED, "on the error output");
    return utils_verbose_on(C_API_VERBOSE_BASIC, dump, &workers) == UTILS_OK ? 0 : 1;
}

    6. C APIAPI C

    Read from include/utils/verbose/CApi.h, included by <utils.h> with the define of the section. Every function that can fail returns UTILS_OK / UTILS_KO (or NULL / 0) and fills utils_exception (see the C API guide).

    Types · Callbacks

    typedef int (*utils_verbose_fn_t)(void* data); // UTILS_OK / UTILS_KO (info: utils_fail / utils_exception_set)
