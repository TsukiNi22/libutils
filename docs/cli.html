    DefineGroupeEspace de nomsEn-têtes

    Une ligne de commande interactive personnalisable : commandes, prompt, historique, flèches, suggestions, auto-complétion, opérateurs logiques, exécutée dans le thread courant ou dans un thread. Le retour à la ligne automatique n'est pas géré.

    1. FlagsFlags

    utils::cli::Flag values are combined with | and set with setFlags, addFlags, subFlags, resetFlags (back to flags::DEFAULT).

    FlagEffect
    DEBUGVerbose for the internal actions (nothing for now)
    NOECHODon't echo the input
    CATCHCatch the exceptions of the commands (code 130) instead of letting them go up
    EMPTY_INPUTIgnore the empty inputs (default: error 127)
    TRIMTrim the input
    PARSEDSplit the input and call the parsed commands (std::vector<std::string>, default: raw std::string)
    PROMPTDisplay the prompt (only on a tty)
    LOGICEnable &&, || and ; between commands (bash semantics)
    ARROWLeft / right arrows in the input
    HISTORYHistory with the up / down arrows
    PERSISTENTKeep the history between sessions (~/.utils-cli_history, 10 000 lines max)
    HINTDisplay a hint when a command fails
    AUTO_COMPLETIONComplete the first command with Tab
    MANUALHandle only call inputs per start (see Start and stop)
    THREADRun in a thread, start returns it
    DETACHEDDetach the thread (start returns nothing, wait with join())
    NO_TTYAllow the usage without a tty (default: CliTTY error)
    Preset (utils::cli::flags::)Content
    DUMBnothing
    DEFAULTCATCH, EMPTY_INPUT, TRIM, PROMPT, ARROW
    TERM1DEFAULT + PARSED, LOGIC, HISTORY
    TERM2TERM1 + HINT, AUTO_COMPLETION
    TERM3TERM2 + THREAD
    LOGTERM3 + DETACHED, NO_TTY
    DEVTERM2 + DEBUG
    MULTI_THREADINGTHREAD, DETACHED

    3. Start and stopDémarrage et arrêt

    MethodDescription
    start(call = 1, failsafe = false)Run the cli; returns the thread with THREAD (not DETACHED), else std::nullopt
    start(input, ...) / start(inputs, ...)Same, executing the given inputs first
    interrupt()Stop after the current input (like Ctrl+C when the constructor gets sig = true)
    kill()Stop, can't be started again
    join()Wait until the cli stops (detached thread)
    isRunning(), wasInterrupted(), wasKilled(), wasStopped()State
    getCode() / strcode(code)Last code and its text
    getHistory()History of the inputs
    setInputDelimitor(c)End of input character (default '\n')

    Cli(true) catches Ctrl+C / Ctrl+Z (the previous handlers are restored by the destructor). The terminal is put in raw mode while the cli runs, only when stdin is a tty.

    Windows: the console is set through utils::platform::tcgetattr / tcsetattr (no line input, no echo, VT input and output); Ctrl+Z is a char (no SIGTSTP), the history is in %USERPROFILE% when HOME is not set.

    MéthodeDescription

    Cli(true) attrape Ctrl+C / Ctrl+Z (les handlers précédents sont restaurés par le destructeur). Le terminal passe en mode raw pendant que la cli tourne, seulement quand stdin est un tty.

    Windows : la console est réglée via utils::platform::tcgetattr / tcsetattr (pas de saisie par ligne, pas d'écho, entrée et sortie VT) ; Ctrl+Z est un caractère (pas de SIGTSTP), l'historique est dans %USERPROFILE% quand HOME n'est pas défini.

    7. ExampleExemple

    #define _Cli
#include <utils/utils.hpp>

int main(void)
{
    utils::cli::Cli cli(true); // catch ctrl-c & ctrl-z
    cli.setFlags(utils::cli::flags::TERM2);
    cli.setCommand("add", std::make_tuple(
        std::function<void(const utils::cli::Cli&, const std::vector<std::string>&)>(
            [](const utils::cli::Cli&, const std::vector<std::string>& args) {
                std::cout << std::stoi(args[1]) + std::stoi(args[2]) << std::endl;
            }),
        std::int16_t{2}, std::int16_t{2} // exactly 2 arguments
    ));
    (void)cli.start();
    return cli.getCode();
}

    8. In CEn C

    Every call of Cli goes through the opaque handle utils_cli_t* (utils_cli_create(sig) / utils_cli_destroy). The thread of THREAD is kept in the handle: wait for it with utils_cli_join.

    C++C
    Cli(sig)utils_cli_create(sig) (NULL on error) / utils_cli_destroy(cli) (kills and joins a running cli)
    setFlags(flags::TERM2)utils_cli_set_flags(cli, C_API_CLI_FLAGS_TERM2) (C_API_CLI_FLAG_* combined with |)
    parsed commandutils_cli_set_parsed_command(cli, name, fn, min, max, data, force), fn(cli, argc, argv, data) with argv[0] = the command
    raw commandutils_cli_set_raw_command(cli, name, fn, data, force)
    start(inputs, call)utils_cli_start(cli, inputs, count, call)
    hooks, middlewaresutils_cli_set_*_hook, utils_cli_<name>_middlewares_add_before / _add_after / _clear
    strcode(code), getHistory()utils_cli_strcode / utils_cli_strcode_r, utils_cli_history_get / _r, utils_cli_history_size
    ParsedDatautils_cli_parsed_t* (utils_cli_parsed_*)

    A callback returns UTILS_OK, UTILS_KO (with utils_fail(code, info) for the message) or C_API_CLI_EXIT to stop the cli like the exit command.

    #define _Cli
#include <utils.h>
#include <stdio.h>
#include <stdlib.h>

static int add(const utils_cli_t* cli, size_t argc, const char* const* argv, void* data)
{
    (void)cli;
    (void)argc;
    (void)data;
    printf("%ld\n", strtol(argv[1], NULL, 10) + strtol(argv[2], NULL, 10));
    return UTILS_OK;
}

int main(void)
{
    utils_cli_t* cli = utils_cli_create(true);   // catch ctrl-c & ctrl-z
    int code = 1;

    if (!cli)
        return 1;
    utils_cli_set_flags(cli, C_API_CLI_FLAGS_TERM2);
    if (utils_cli_set_parsed_command(cli, "add", add, 2, 2, NULL, false) == UTILS_OK
        && utils_cli_start(cli, NULL, 0, 1) == UTILS_OK)
        code = utils_cli_get_code(cli);
    else
        fprintf(stderr, "%s\n", utils_exception_format());
    utils_cli_destroy(cli);
    return code;
}

    Chaque appel de Cli passe par le handle opaque utils_cli_t* (utils_cli_create(sig) / utils_cli_destroy). Le thread de THREAD est gardé dans le handle : attendez-le avec utils_cli_join.

    C++C
    Cli(sig)utils_cli_create(sig) (NULL en cas d'erreur) / utils_cli_destroy(cli) (tue et attend une cli en cours)
    setFlags(flags::TERM2)utils_cli_set_flags(cli, C_API_CLI_FLAGS_TERM2) (C_API_CLI_FLAG_* combinés avec |)
    commande parséeutils_cli_set_parsed_command(cli, name, fn, min, max, data, force), fn(cli, argc, argv, data) avec argv[0] = la commande
    commande bruteutils_cli_set_raw_command(cli, name, fn, data, force)
    start(inputs, call)utils_cli_start(cli, inputs, count, call)
    hooks, middlewaresutils_cli_set_*_hook, utils_cli_<name>_middlewares_add_before / _add_after / _clear
    strcode(code), getHistory()utils_cli_strcode / utils_cli_strcode_r, utils_cli_history_get / _r, utils_cli_history_size
    ParsedDatautils_cli_parsed_t* (utils_cli_parsed_*)

    Un callback renvoie UTILS_OK, UTILS_KO (avec utils_fail(code, info) pour le message) ou C_API_CLI_EXIT pour arrêter la cli comme la commande exit.
