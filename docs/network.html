    A TCP Server and Client built on a socket object. The messages (payloads) are strings separated by '\n' by default; listen reads what is available without blocking, join waits for the next event. Same API on Unix and Windows (the epoll is emulated over WSAPoll on Windows, see Platform). The layers and the EETP protocol are explained in Communication.

    Un Server et un Client TCP construits sur un objet socket. Les messages (payloads) sont des chaînes séparées par '\n' par défaut ; listen lit ce qui est disponible sans bloquer, join attend le prochain événement. Même API sous Unix et Windows (l'epoll est émulé par-dessus WSAPoll sous Windows, voir Platform). Les couches et le protocole EETP sont expliqués dans Communication.

    2. ServerServer

    Server(std::shared_ptr<ISocket> socket, Address address = {}): every client is identified by its fd.

    MethodDescription
    start()Listen on the address (restart after a stop)
    stop() / kill()Close every connection; after kill the server can't be restarted
    listen()Accept the new clients, read what is available, return fd → Payloads (cleared at the next call)
    listen(fd)Same for one client (UnknownFd if not connected)
    join(fd = -1)Wait for the next event (any client, or one fd)
    send<buffered = false>(fd, payload)Send now, or store it until flush
    flush() / flush(fd)Send the stored payloads
    getFds()Connected clients
    getStatus()Status

    4. ThreadsThreads

    stop() and kill() can be called from another thread while a listen / join runs: the join returns, the epoll is closed when the last join leaves. Sending to a closed peer never raises SIGPIPE.

    stop() et kill() peuvent être appelés depuis un autre thread pendant qu'un listen / join tourne : le join retourne, l'epoll est fermé quand le dernier join se termine. Un envoi vers un pair fermé ne lève jamais SIGPIPE.

    5. ExampleExemple

    #define _Network
#include <utils/utils.hpp>

// Server: echo every payload
utils::network::Server server(std::make_shared<utils::network::TCPSocket>(), {{"", ""}, 4242});
server.start();
while (server.getStatus() == utils::network::Status::Up) {
    server.join();
    for (const auto& [fd, payloads]: server.listen())
        for (const utils::network::Payload& payload: payloads)
            server.send(fd, payload);
}

// Client
utils::network::Client client(std::make_shared<utils::network::TCPSocket>(), {{"127.0.0.1", ""}, 4242});
client.start();
client.send("hello");
client.join();
for (const utils::network::Payload& payload: client.listen())
    std::cout << payload << std::endl;

    7. SocketSocket

    The socket layer used by the Server and the Client: it opens the connection, splits the stream into payloads and buffers what is not complete yet. One socket object handles every fd of a server (each method takes the fd, -1 = the socket itself). Same API on Unix and Windows (Winsock 2 through Platform).

    ClassDescription
    ISocketInterface used by the Server / Client
    ASocketCommon implementation: buffers, payload splitting, overflow check
    TCPSocketTCP implementation (connect, listen, accept, recv, send of Platform, MSG_NOSIGNAL)

    Connection

    MethodDescription
    connect(address)Connect as a client
    listen(address)Listen as a server
    accept()Accept a new client, return its fd (server only)
    close()Close the socket, connect / listen can be used again
    reset()Forget the fd and the buffers without closing the fd
    getFd()fd of the socket (-1 = closed)

    Payloads

    MethodDescription
    send(s, fd = -1)Send s followed by the separator now
    sendBuffered(s, fd = -1) / flush(fd = -1)Store the payload, send the stored ones
    receive(fd = -1)Read once (after a poll event) into the internal buffer, never waits for a full payload, returns the number of bytes read
    recv(fd = -1)Read until one full payload is available and return it (the rest stays in the buffer)
    recvAll(fd = -1)Return every full payload of the buffer
    empty(fd = -1)No full payload in the buffer
    discard(fd = -1)Forget the buffers of a fd (closed client), -1 = every fd

    Settings

    MethodDefaultDescription
    setPayloadSeparator(char) / setPayloadSeparator(std::string)'\n'End of a payload (an empty separator = raw mode, every read is a payload)
    setChunckSize(size)4096Bytes read per call
    setOverflow(size)4048Characters without a separator before a Socket error (0 = unlimited)

    Tools

    FunctionDescription
    is_ip(s)Is s an IPv4 address
    resolve_hostname(hostname)IPv4 of a hostname
    resolve_address(address)Fill the ip of the Address from its hostname (done by the Client constructor)

    Custom socket

    TCPSocket is final on its methods: a new transport derives ASocket, implements connect / listen and the 3 system calls, and returns true from the matching has*Overload() so that ASocket uses them (the buffering and payload splitting stay the ones of ASocket).

    #define _Socket
#include <utils/utils.hpp>

class MySocket: public utils::network::ASocket {
    public:
        void connect(const utils::network::Address& address) override; // set the fd of the socket
        void listen(const utils::network::Address& address) override;

        bool hasAcceptOverload(void) const override {return true;};
        bool hasRecvOverload(void) const override   {return true;};
        bool hasSendOverload(void) const override   {return true;};
        int accept(int fd, sockaddr* addr, socklen_t* len) const override;
        ssize_t recv(int fd, char* buf, std::size_t len) const override;
        ssize_t send(int fd, const char* buf, std::size_t len) const override;
};

utils::network::Server server(std::make_shared<MySocket>(), {{"", ""}, 4242});

    La couche socket utilisée par le Server et le Client : elle ouvre la connexion, découpe le flux en payloads et garde en buffer ce qui n'est pas encore complet. Un seul objet socket gère tous les fd d'un serveur (chaque méthode prend le fd, -1 = le socket lui-même). Même API sous Unix et Windows (Winsock 2 via Platform).

    ClasseDescription
    ISocketInterface utilisée par le Server / Client
    ASocketImplémentation commune : buffers, découpage en payloads, contrôle de l'overflow
    TCPSocketImplémentation TCP (connect, listen, accept, recv, send de Platform, MSG_NOSIGNAL)

    Connexion

    MéthodeDescription
    connect(address)Se connecte en tant que client
    listen(address)Écoute en tant que serveur
    accept()Accepte un nouveau client, renvoie son fd (serveur seulement)
    close()Ferme le socket, connect / listen peuvent être réutilisés
    reset()Oublie le fd et les buffers sans fermer le fd
    getFd()fd du socket (-1 = fermé)

    Payloads

    MéthodeDescription
    send(s, fd = -1)Envoie s suivi du séparateur, tout de suite
    sendBuffered(s, fd = -1) / flush(fd = -1)Stocke le payload, envoie ceux qui sont stockés
    receive(fd = -1)Lit une fois (après un événement de poll) dans le buffer interne, n'attend jamais un payload complet, renvoie le nombre d'octets lus
    recv(fd = -1)Lit jusqu'à ce qu'un payload complet soit disponible et le renvoie (le reste reste dans le buffer)
    recvAll(fd = -1)Renvoie tous les payloads complets du buffer
    empty(fd = -1)Aucun payload complet dans le buffer
    discard(fd = -1)Oublie les buffers d'un fd (client fermé), -1 = tous les fd

    Réglages

    MéthodeDéfautDescription
    setPayloadSeparator(char) / setPayloadSeparator(std::string)'\n'Fin d'un payload (un séparateur vide = mode brut, chaque lecture est un payload)
    setChunckSize(size)4096Octets lus par appel
    setOverflow(size)4048Caractères sans séparateur avant une erreur Socket (0 = illimité)

    Socket personnalisé

    TCPSocket est final sur ses méthodes : un nouveau transport dérive d'ASocket, implémente connect / listen et les 3 appels système, et renvoie true depuis le has*Overload() correspondant pour qu'ASocket les utilise (le buffering et le découpage en payloads restent ceux d'ASocket).

    #define _Socket
#include <utils/utils.hpp>

class MySocket: public utils::network::ASocket {
    public:
        void connect(const utils::network::Address& address) override; // set the fd of the socket
        void listen(const utils::network::Address& address) override;

        bool hasAcceptOverload(void) const override {return true;};
        bool hasRecvOverload(void) const override   {return true;};
        bool hasSendOverload(void) const override   {return true;};
        int accept(int fd, sockaddr* addr, socklen_t* len) const override;
        ssize_t recv(int fd, char* buf, std::size_t len) const override;
        ssize_t send(int fd, const char* buf, std::size_t len) const override;
};

utils::network::Server server(std::make_shared<MySocket>(), {{"", ""}, 4242});
