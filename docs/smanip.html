    Outils de chaînes : texte stylé avec des balises, chaînes à la compilation, codecs et parsers. Les séquences du terminal sont dans IOManip.

    1. formatformat

    utils::smanip::format(s) replaces the tags <style|style|...> by the ANSI sequences (IOManip), <> resets the style. Unknown styles are ignored, the names are case insensitive.

    Styles: reset, strong, dark, italic, underlined, flashing_fast, flashing_slow, reversed, hide, bar, monospace, framed, encircled, overlined, exposant, indice.

    std::cout << utils::smanip::format("<strong|underlined>USAGE<> ./app [options]") << std::endl;

    utils::smanip::format(s) remplace les balises <style|style|...> par les séquences ANSI (IOManip), <> réinitialise le style. Les styles inconnus sont ignorés, les noms ne tiennent pas compte de la casse.

    Styles : reset, strong, dark, italic, underlined, flashing_fast, flashing_slow, reversed, hide, bar, monospace, framed, encircled, overlined, exposant, indice.

    std::cout << utils::smanip::format("<strong|underlined>USAGE<> ./app [options]") << std::endl;

    4. ParserParser

    IParser<T> / AParser<T>: format(content) / parse(s), and format(id, content) / parse(id, s) for the parsers that keep a state per peer.

    EETP protocol

    parser::EETPParser frames and encrypts the messages of a client / server connection (the id is the peer). A message is an EETPContent{type, data} (type of typeSize characters, default 1). The exchange is drawn in Communication.

    Type (Char)Role
    SYNClient → server: the client RSA public key, encrypted with the common RSA key
    SOServer → client: a new AES-256 key, encrypted with the client public key
    EMDisconnection, never encrypted, no data
    ACK / NAKAt most one data
    any otherData encrypted with AES-256-GCM, a new random iv for each message

    Frame: <tag> ETB <content>, the tag being <iv><GCM tag> (empty for the RSA / clear types), each part encoded with the codec (default Base64Codec, setCodec).

    #define _SManip
#include <utils/utils.hpp>

utils::smanip::parser::EETPParser client, server; // common RSA key read from ~/.ssh/common(.pub)
std::string syn = client.format("server", {std::string(1, static_cast<char>(utils::iomanip::Char::SYN)), {}});
(void)server.parse("client", syn);
std::string so = server.format("client", {std::string(1, static_cast<char>(utils::iomanip::Char::SO)), {}});
(void)client.parse("server", so);

std::string framed = client.format("server", {"A", {"hello", "world"}});
utils::smanip::parser::EETPContent content = server.parse("client", framed); // type "A", data {"hello", "world"}

    Warning. Both sides must use v3.0.0 or later (framing changed). A tampered message fails the GCM authentication (Decryption, or Codec when the encoding is broken), a malformed frame throws Parser.

    IParser<T> / AParser<T> : format(content) / parse(s), et format(id, content) / parse(id, s) pour les parsers qui gardent un état par pair.

    Protocole EETP

    parser::EETPParser encadre et chiffre les messages d'une connexion client / serveur (l'id est le pair). Un message est un EETPContent{type, data} (type de typeSize caractères, 1 par défaut). L'échange est schématisé dans Communication.

    Type (Char)Rôle
    SYNClient → serveur : la clé publique RSA du client, chiffrée avec la clé RSA commune
    SOServeur → client : une nouvelle clé AES-256, chiffrée avec la clé publique du client
    EMDéconnexion, jamais chiffrée, pas de données
    ACK / NAKAu plus une donnée
    tout autreDonnées chiffrées en AES-256-GCM, un nouvel iv aléatoire pour chaque message

    Trame : <tag> ETB <content>, le tag étant <iv><GCM tag> (vide pour les types RSA / en clair), chaque partie encodée avec le codec (par défaut Base64Codec, setCodec).

    #define _SManip
#include <utils/utils.hpp>

utils::smanip::parser::EETPParser client, server; // common RSA key read from ~/.ssh/common(.pub)
std::string syn = client.format("server", {std::string(1, static_cast<char>(utils::iomanip::Char::SYN)), {}});
(void)server.parse("client", syn);
std::string so = server.format("client", {std::string(1, static_cast<char>(utils::iomanip::Char::SO)), {}});
(void)client.parse("server", so);

std::string framed = client.format("server", {"A", {"hello", "world"}});
utils::smanip::parser::EETPContent content = server.parse("client", framed); // type "A", data {"hello", "world"}

    Attention. Les deux côtés doivent utiliser v3.0.0 ou plus récent (la trame a changé). Un message altéré échoue à l'authentification GCM (Decryption, ou Codec quand l'encodage est cassé), une trame mal formée lève Parser.

    A codec given to a parser (utils_eetp_parser_create_with, utils_eetp_parser_set_codec) belongs to the parser on success: never destroy or use it after.

    #define _SManip
#include <utils.h>
#include <stdio.h>
#include <string.h>

int main(void)
{
    utils_codec_t* codec = utils_codec_create_base64();
    utils_string_t* encoded = utils_string_create(NULL, 0);
    utils_string_t* decoded = utils_string_create(NULL, 0);
    int ret = 1;

    if (codec && encoded && decoded
        && utils_codec_encode(codec, "hello", strlen("hello"), encoded) == UTILS_OK
        && utils_codec_decode(codec, utils_string_data(encoded), utils_string_size(encoded), decoded) == UTILS_OK) {
        printf("%s -> %s\n", utils_string_data(encoded), utils_string_data(decoded)); // aGVsbG8= -> hello
        printf("%s\n", utils_smanip_format("<strong|underlined>USAGE<> ./app [options]"));
        ret = 0;
    }
    utils_string_destroy(decoded);
    utils_string_destroy(encoded);
    utils_codec_destroy(codec);
    return ret;
}
