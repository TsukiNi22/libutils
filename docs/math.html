    2. GeometryGéométrie

    FunctionDescription
    rotate_point_2D(origin, point, angle, rad = false)Rotate point around origin by angle (degrees, radians with rad = true)
    rotate_point_3D(origin, point, orientation, rad = false)Rotate point around origin by the orientation angles {pitch (x), yaw (y), roll (z)}
    to_look(orientation)Normalized look vector of an orientation

    Convention: y up, forward = +z. rotate_point_3D and to_look use the same one: rotating the forward vector (0, 0, 1) by an orientation gives to_look(orientation).

    #define _Geometry
#include <utils/utils.hpp>

utils::math::Coord2D p = utils::math::geometry::rotate_point_2D({0, 0}, {1, 0}, 90); // ~(0, 1)
utils::math::Direction look = utils::math::geometry::to_look({0, 90, 0});           // ~(1, 0, 0)
    FonctionDescription
    rotate_point_2D(origin, point, angle, rad = false)Fait tourner point autour de origin de angle (degrés, radians avec rad = true)
    rotate_point_3D(origin, point, orientation, rad = false)Fait tourner point autour de origin des angles de orientation {pitch (x), yaw (y), roll (z)}
    to_look(orientation)Vecteur de visée normalisé d'une orientation

    Convention : y vers le haut, avant = +z. rotate_point_3D et to_look utilisent la même : faire tourner le vecteur avant (0, 0, 1) d'une orientation donne to_look(orientation).

    #define _Geometry
#include <utils/utils.hpp>

utils::math::Coord2D p = utils::math::geometry::rotate_point_2D({0, 0}, {1, 0}, 90); // ~(0, 1)
utils::math::Direction look = utils::math::geometry::to_look({0, 90, 0});           // ~(1, 0, 0)

    4. In CEn C

    The math types are plain C structures passed by value (utils_math_type_t = double).

    C++C
    Coord2D / UCoord2Dutils_math_coord2d_t / utils_math_ucoord2d_t {x, y}
    Coord / UCoord / Directionutils_math_coord_t / utils_math_ucoord_t / utils_math_direction_t {x, y, z}
    Chunk, CFrameutils_math_chunk_t, utils_math_cframe_t {position, orientation, look}
    rotate_point_2D / rotate_point_3D / to_lookutils_math_rotate_point_2d / utils_math_rotate_point_3d / utils_math_to_look
    deg_to_rad / rad_to_degutils_math_deg_to_rad / utils_math_rad_to_deg
    #define _Geometry
#define _Trigo
#include <utils.h>
#include <stdio.h>

int main(void)
{
    utils_math_coord2d_t origin = {0, 0};
    utils_math_coord2d_t point = {1, 0};
    utils_math_coord2d_t p = utils_math_rotate_point_2d(origin, point, 90, false);    // ~(0, 1)
    utils_math_direction_t look = utils_math_to_look((utils_math_direction_t){0, 90, 0}); // ~(1, 0, 0)

    printf("(%.2f, %.2f) (%.2f, %.2f, %.2f) %f\n", p.x, p.y, look.x, look.y, look.z, utils_math_deg_to_rad(180));
    return 0;
}

    5. C++ APIAPI C++

    Read from the headers of include/utils/math/ (public part only, the trailing comments of the code kept). Include <utils/utils.hpp> with the define of the section, never these headers one by one.

    utils/math/MathType.hpp

    Type definition used in math computing

    // namespace utils::math
using Type = double; // Type used everywhere for coord, angle, direction, ...
using UType = std::uint64_t; // Type used everywhere for unsigned coord, angle, direction, ...
using V2Type = utils::type::OVector2<utils::math::Type>;
using Coord2D = utils::type::OVector2<utils::math::Type>;
using V2UType = utils::type::OVector2<utils::math::UType>;
using UCoord2D = utils::type::OVector2<utils::math::UType>;
using V3Type = utils::type::OVector3<utils::math::Type>;
using Coord = utils::type::OVector3<utils::math::Type>;
using V3UType = utils::type::OVector3<utils::math::UType>;
using UCoord = utils::type::OVector3<utils::math::UType>;
using Angle = utils::math::Type; // Generaly in deg
using Direction = utils::type::OVector3<utils::math::Angle>; // Generaly normalized
using Chunk = utils::type::OVector3<std::int32_t>; // Used for spacial partitionning
struct CFrame {
    utils::math::Coord position = {0.0, 0.0, 0.0}; // Coord
    utils::math::Direction orientation = {0.0, 0.0, 0.0}; // Orientation in deg
    utils::math::Direction look = {0.0, 0.0, 0.0}; // Orientation normalized
};
