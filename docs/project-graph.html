    Project graphGraphe du projet

    An interactive 2D / 3D graph of the files, classes, functions, calls and tests of libutils.Un graphe interactif 2D / 3D des fichiers, classes, fonctions, appels et tests de libutils.

    Updated 2026-11-26

    The project graph draws the whole repository: the headers and sources, the classes and functions, the includes, the calls, the tests and the build targets, filtered by category or by relation, in 2D or 3D.

    Le graphe du projet dessine tout le dépôt : les headers et les sources, les classes et les fonctions, les includes, les appels, les tests et les cibles de build, filtrés par catégorie ou par relation, en 2D ou en 3D.
