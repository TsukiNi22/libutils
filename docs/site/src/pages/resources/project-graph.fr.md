Le [graphe du projet](graph.html) dessine tout le dépôt : les headers et les sources, les classes et les fonctions, les includes, les appels, les tests et les cibles de build, filtrés par catégorie ou par relation, en 2D ou en 3D.

## Utilisation {#use}

| Action | Comment |
|---|---|
| Trouver un fichier, une classe ou une fonction | la barre de recherche du graphe |
| N'afficher qu'un type de nœud ou de relation | les filtres (catégories, groupes, relations) |
| Voir ce qui dépend d'un nœud | le sélectionner : ses voisins sont mis en évidence |
| Changer de vue | le bouton 2D / 3D |
