    1. KeysClés

    Every key derives IKey<T> / AKey<T> (T = the key data):

    MethodDescription
    generate()Generate a new key
    set(data) / get()Set / get the key data
    encrypt(s) / decrypt(s)With the stored key
    encrypt(s, data) / decrypt(s, data)With a key given at the call (data can be updated, ex: the AES tag)
    generateRandomBytes(size = 32)Random bytes (OpenSSL RAND_bytes)
    hasGenerateOverload(), hasSetOverload(), hasGetOverload()What the key implements

    Warning. A method a key doesn't implement ends with FatalException(UndefinedCall) (ex: AESKey::generate()).

    Chaque clé dérive de IKey<T> / AKey<T> (T = les données de la clé) :

    MéthodeDescription
    generate()Génère une nouvelle clé
    set(data) / get()Définit / récupère les données de la clé
    encrypt(s) / decrypt(s)Avec la clé stockée
    encrypt(s, data) / decrypt(s, data)Avec une clé donnée à l'appel (data peut être mis à jour, ex : le tag AES)
    generateRandomBytes(size = 32)Octets aléatoires (RAND_bytes d'OpenSSL)
    hasGenerateOverload(), hasSetOverload(), hasGetOverload()Ce que la clé implémente

    Attention. Une méthode qu'une clé n'implémente pas se termine par FatalException(UndefinedCall) (ex : AESKey::generate()).

    2. AESKeyAESKey

    AES-256-GCM, the key is given at each call: KeyAES{AES, iv, tag}.

    FieldSize
    AES32 bytes (AES_KEY_SIZE)
    ivat least 12 bytes (AES_MIN_IV_SIZE), a new one for every message
    tag16 bytes (AES_TAG_SIZE), written by encrypt, checked by decrypt
    #define _Encryption
#include <utils/utils.hpp>

utils::security::encryption::AESKey aes;
utils::security::encryption::KeyAES key{aes.generateRandomBytes(32), aes.generateRandomBytes(12), ""};
std::string cipher = aes.encrypt("secret", key);   // key.tag is set
std::string plain = aes.decrypt(cipher, key);      // "secret", Decryption error if modified

    Wrong sizes throw Encryption / Decryption, data over 2 GiB OutOfBounds.

    AES-256-GCM, la clé est donnée à chaque appel : KeyAES{AES, iv, tag}.

    ChampTaille
    AES32 octets (AES_KEY_SIZE)
    ivau moins 12 octets (AES_MIN_IV_SIZE), un nouveau pour chaque message
    tag16 octets (AES_TAG_SIZE), écrit par encrypt, vérifié par decrypt
    #define _Encryption
#include <utils/utils.hpp>

utils::security::encryption::AESKey aes;
utils::security::encryption::KeyAES key{aes.generateRandomBytes(32), aes.generateRandomBytes(12), ""};
std::string cipher = aes.encrypt("secret", key);   // key.tag is set
std::string plain = aes.decrypt(cipher, key);      // "secret", Decryption error if modified

    Des tailles incorrectes lèvent Encryption / Decryption, des données de plus de 2 Gio OutOfBounds.

    3. RSAKeyRSAKey

    RSA with OAEP padding, KeyPair{priv, pub} in PEM. Data of any size (encrypted block by block).

    4. CommonRSAKeyCommonRSAKey

    An RSAKey loaded from files shared by both sides (used by the EETP handshake, SManip): loadCommon(path = "~/.ssh/common") reads <path> (private) and <path>.pub (public).

    FunctionDescription

    string_to_key(std::string)std::string to bytes

    keyToString / stringToKey (renamed key_to_string / string_to_key in v3.0.0) were removed in v4.0.0.

    Une RSAKey chargée depuis des fichiers partagés par les deux côtés (utilisée par le handshake EETP, SManip) : loadCommon(path = "~/.ssh/common") lit <path> (privée) et <path>.pub (publique).

    FonctionDescription

    5. ObserverObserver

    Most classes of the library inherit Observer<"Name">: each instance registers an id in a global handler, and the memory leak notifier reports the instances still alive when the program ends.

    ClassDescription
    Observer<"Name">Tracks the instances of a class (thread safe)
    UnsafeObserver<"Name">Same without lock
    AObserver<"Name", safe_mode> / IObserverBase classes
    INotifier / ANotifierlink(id, instance), unlink(id), clear(), trigger()
    MemoryLeakNotifierAt exit (or on trigger()), prints the classes still alive and their count
    instances::id_handler()Global IdHandler<std::uint64_t> of the observers
    instances::notifiers()Array of the notifiers ([0] = MemoryLeakNotifier)

    Inherit it privately: class Server: private utils::security::observer::Observer<"Server">. Output of a leak:

    [WARNING] Memory leak detected (origin: <module>)
-- At least one instance wasn't properly closed --
  2 - ISocket
  1 - Client
    #include <utils/utils.hpp>
#include <utils/security/observer/Observer.hpp>

class Session: private utils::security::observer::Observer<"Session"> {};

int main(void)
{
    new Session(); // never deleted: reported at exit
    return 0;
}

    La plupart des classes de la bibliothèque héritent de Observer<"Name"> : chaque instance enregistre un id dans un handler global, et le notifier de fuites mémoire signale les instances encore en vie à la fin du programme.

    ClasseDescription
    Observer<"Name">Suit les instances d'une classe (thread safe)
    UnsafeObserver<"Name">Pareil sans verrou
    AObserver<"Name", safe_mode> / IObserverClasses de base
    INotifier / ANotifierlink(id, instance), unlink(id), clear(), trigger()
    MemoryLeakNotifierÀ la sortie (ou sur trigger()), affiche les classes encore en vie et leur nombre
    instances::id_handler()IdHandler<std::uint64_t> global des observers
    instances::notifiers()Tableau des notifiers ([0] = MemoryLeakNotifier)

    Héritez-en en privé : class Server: private utils::security::observer::Observer<"Server">. Sortie d'une fuite :

    [WARNING] Memory leak detected (origin: <module>)
-- At least one instance wasn't properly closed --
  2 - ISocket
  1 - Client
    #include <utils/utils.hpp>
#include <utils/security/observer/Observer.hpp>

class Session: private utils::security::observer::Observer<"Session"> {};

int main(void)
{
    new Session(); // never deleted: reported at exit
    return 0;
}

    6. In CEn C

    C++C
    AESKey + KeyAESutils_aes_key_t* + utils_aes_data_t* (utils_aes_data_set_key / _set_iv, the tag set by utils_aes_key_encrypt)
    RSAKey / CommonRSAKeyutils_rsa_key_t*: utils_rsa_key_create() then utils_rsa_key_generate, or utils_rsa_key_create_common(path) (NULL = ~/.ssh/common)
    encrypt / decryptutils_aes_key_encrypt(key, in, size, data, out), utils_rsa_key_encrypt(key, in, size, out)... into a utils_string_t* (SManip)
    Observer<"Name">utils_observer_t*: utils_observer_create(instance, safe_mode); an observer never destroyed is reported as a leak; utils_observer_trigger() reports now
    #define _Encryption
#define _SManip
#include <utils.h>
#include <stdio.h>
#include <string.h>

int main(void)
{
    utils_aes_key_t* aes = utils_aes_key_create();
    utils_aes_data_t* data = utils_aes_data_create();
    utils_string_t* bytes = utils_string_create(NULL, 0);
    utils_string_t* cipher = utils_string_create(NULL, 0);
    utils_string_t* plain = utils_string_create(NULL, 0);
    int ret = 1;

    if (aes && data && bytes && cipher && plain
        && utils_aes_key_random_bytes(aes, 32, bytes) == UTILS_OK
        && utils_aes_data_set_key(data, utils_string_data(bytes), utils_string_size(bytes)) == UTILS_OK
        && utils_aes_key_random_bytes(aes, 12, bytes) == UTILS_OK
        && utils_aes_data_set_iv(data, utils_string_data(bytes), utils_string_size(bytes)) == UTILS_OK
        && utils_aes_key_encrypt(aes, "secret", strlen("secret"), data, cipher) == UTILS_OK  // the tag of data is set
        && utils_aes_key_decrypt(aes, utils_string_data(cipher), utils_string_size(cipher), data, plain) == UTILS_OK) {
        printf("%s\n", utils_string_data(plain)); // secret
        ret = 0;
    }
    utils_string_destroy(plain);
    utils_string_destroy(cipher);
    utils_string_destroy(bytes);
    utils_aes_data_destroy(data);
    utils_aes_key_destroy(aes);
    return ret;
}
